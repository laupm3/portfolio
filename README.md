# Laura Prieto · Personal Portfolio

Un portfolio moderno y profesional diseñado con una estética Cyber/Premium, enfocado en el desarrollo Frontend.

![Laura Prieto Portfolio](/public/screenshot.png) *(Próximamente)*

## ✨ Características Principales

- 🌐 **Multilingüe (i18n)**: Soporte completo para Español e Inglés (Auto-detección y selector manual).
- 🌓 **Sistema de Temas**: Modo oscuro (Cyber) y modo claro elegantes, con persistencia.
- 📱 **Diseño Responsive**: Optimizado para dispositivos móviles, tablets y escritorio.
- ⚡ **Alto Rendimiento**: Carga rápida y animaciones fluidas con Framer Motion.
- 🖼️ **Iconografía Premium**: Uso de Lucide React para interfaces limpias.
- 🎨 **Accesibilidad**: Navegación mejorada con enlaces de salto y etiquetas ARIA.

## 🛠️ Stack Tecnológico

- **Frontend**: [React 18](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Estilos**: [Tailwind CSS](https://tailwindcss.com/)
- **Animaciones**: [Framer Motion](https://www.framer.com/motion/)
- **Internacionalización**: [i18next](https://www.i18next.com/)
- **Iconos**: [Lucide React](https://lucide.dev/)

## 📂 Estructura del Proyecto

```bash
src/
├── components/
│   ├── layout/       # Componentes de estructura (Container, Footer)
│   ├── sections/     # Secciones de la página principal (Hero, About, Projects, etc.)
│   └── ui/           # Componentes de UI reutilizables (Navbar, Toggles)
├── data/             # Información centralizada (Perfil, Proyectos, Servicios)
├── locales/          # Archivos de traducción JSON (ES/EN)
├── pages/            # Páginas principales (Home)
├── App.jsx           # Componente raíz y configuración de layout
└── i18n.js           # Configuración de internacionalización
```

## 🚀 Instalación y Desarrollo

1. Clona el repositorio:
   ```bash
   git clone https://github.com/laupm3/portfolio.git
   ```
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```

## ⚙️ Configuración Personal

Toda la información personal se encuentra centralizada en `src/data/profile.js`. Puedes actualizar tu nombre, rol, redes sociales y foto allí.
